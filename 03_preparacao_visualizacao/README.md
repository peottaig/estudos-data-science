# Preparação e visualização de dados

Esta pasta reúne meus estudos de limpeza, tratamento e visualização de dados. Os notebooks abordam valores ausentes, dados duplicados, padronização, valores fora do domínio e construção de gráficos com Matplotlib e seaborn.

Os exercícios foram desenvolvidos por mim para praticar a preparação de bases e a comunicação de informações por meio de visualizações.
